# Gemini Operationalization Plan (Ultra-Detailed Blueprint)

This document provides a definitive, call-by-call operationalization of the experiment procedure. It is designed to be an unambiguous blueprint for implementation, detailing the sequence of agent calls, the precise data payloads, the role of the "Participant" and "Util" agents, all internal system logic, and the data logged at each stage.

**Actors:**
*   **System:** The core orchestrator, executing code and managing state.
*   **Participant Agent (PA):** The main agent participating in the experiment.
*   **Util Agent (UA):** A specialized service agent for parsing, validation, and explanation generation.

**System State Management:**
*The System must maintain a state object for each PA, e.g., `agent_states['agent_N']`, containing their full memory, choices, payouts, and a `bank_account`. It also manages global state like the current phase and round number.*
